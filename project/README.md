# CDLE semester project

This is a separate workstream from the weekly laboratories.

Suggested workflow: approved theme and research question → proposal and checkpoints → reproducible implementation (batch, streaming, lakehouse, if required by the final brief) → tests, benchmarks, results → research report → presentation and individual defence.

Do not invent the project specification: update this document once the project statement, theme and group decisions are available.

- `planning/`: proposal, requirements, milestones and task ownership.
- `docs/`: architecture and decisions.
- `src/`: implementation modules.
- `tests/`: unit and integration tests, small fixtures.
- `experiments/`: protocols and **small** evidence/metrics only.
- `report/`: drafts, figures and bibliography.
- `presentation/`: final slides and speaking notes.
- `ai-usage.md`: transparent AI use for the project.
